# walker.png

会话页输入区上沿那条线上走动的小人，两帧：左边站立、右边迈步。轮流播放就是一个走路循环，
迈步那一帧本身画得比站立高一像素，走起来自带上下颠簸，不用再另加动画。

**正本不在这儿。** 整套素材（九个角色的总表、格子怎么读、怎么裁出新的一版、出处与授权）
在 `src/frago/resources/mascot/`，那份随包分发，仓库之外也取得到。这里这张只是同一张图的
副本——前端源码不随包走，构建时又会把它编码进样式，所以前端得自己留一份。
**换角色两边都要换。**

- 出处：Kenney「Pixel Platformer」，Creative Commons CC0 1.0，可商用、免署名。
- 每帧 20×24，两帧并排共 40×24。换帧就是把背景横向挪 20 像素，比两个文件来回换稳。
- 只有 492 字节：构建时直接内联进样式表，页面不会为它多发一次请求。
