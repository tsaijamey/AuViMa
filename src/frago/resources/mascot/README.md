# 吉祥物素材

frago 界面上那个会走路的像素小人，以及他的八个同伴。这里是**唯一的正本**：随包分发，
装了 frago 就有，任何功能（配方生成图、桌面舞台、文档配图、别的页面）都能按路径取。

## 两个文件

| 文件 | 是什么 |
|---|---|
| `characters.png` | 角色总表，216×72，九列三行，每格 24×24，格与格之间不留缝 |
| `walker.png` | 会话页此刻在用的那一版：戴头盔的人，站立与迈步两帧并排，每帧 20×24 |

## 总表怎么读

九列三行共二十七格，按行从左到右、从上到下编号 0–26。**相邻两格是同一个角色的两帧**
（站立、迈步），轮流播放就是一个走路循环：

| 角色 | 格子 |
|---|---|
| 绿外星人 | 0, 1 |
| 蓝外星人 | 2, 3 |
| 粉外星人 | 4, 5 |
| 黄外星人 | 6, 7 |
| 戴头盔的人（当前在用） | 9, 10 |
| 方脸怪 | 11, 12 |
| 小黄人 | 13, 14 |
| 坦克 | 18, 19 |
| 蝙蝠 | 24, 25 |

第 8、15–17、20–23、26 格是单帧或三帧的载具，没有成对的走路循环。

## 换一个角色

`walker.png` 是从总表里裁出来的：取那个角色的两格，各自去掉左右两像素空白（人物实际只占
中间 20 像素），并排放进一张 40×24 的图。换角色就是换这一张，格式不变，用它的地方一行都
不用改。

## 会话页那一份为什么是复制的一份

网页界面由 `src/frago/client` 构建，而前端源码不随包走（打包时被排除），构建产物里这张图
已经被编码进样式、看不出原样。所以前端自己留了一份 `src/frago/client/src/assets/walker.png`，
与这里的 `walker.png` 是同一张图。**改角色两边都要换**，正本以这里为准。
